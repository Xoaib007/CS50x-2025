###
CLI commands:
1. cd : Change Directory - Change directory (folder) in the file system
2. cp : Copy - Copy a file to another folder
3. ls : List - List the directory (folder) system
4. mkdir : Make Directory - Creates a new directory (folder)
5. mv : Move - Move a file to another folder
6. rm : Remove - Remove a file
7. rmdir : Removr Directory - Remove a directory (folder)
8. clear : Clears the CLI window
9. exit : Closes the CLI window
